# Trip photos

Photos from the New York trip (February 2027), one folder for the whole trip. JPEG, at most
1600 px on the long side, named `<date>-<n>.jpg` (for example `2027-02-04-1.jpg`). Each photo is
listed under its day in `src/features/trip/itinerary.ts`; the test fails if a listed file is
missing or its letter case differs.
